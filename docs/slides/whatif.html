What happens when something goes wrong? Clearing needs all three operators, so if one stops, the auction cannot settle; instead the other two refund every deposit, signing 2-of-3 without the stopped operator’s key share. A settlement that crashes midway resumes from the operators’ journals with the same prepared transaction, never a second payment, and a refunded book can never also be settled. A corrupted receipt is refused before a bidder’s key is read. Two limits remain, and we state them: if two operators stop, the deposits wait; and two colluding operators could sign a different payout, which would then fail public verification.
