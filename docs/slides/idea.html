The idea

One proof system for each problem

REP3 · MPC

Split

Each bidder’s client splits the bid into secret shares. No operator can read one.

coNoir · ZK

Prove

Three operators prove the price together from the shares. No one holds the bid book.

Halo2

Pay

Four refunds, the seller and the fee: each payout has its own proof that it matches the result.

FROST · 2-of-3

Custody

The escrow’s Ironwood spends are signed by any two operators. No master key exists.

All six payouts settle in one shielded Zcash transaction that anyone can verify.

DarkCall · ZECATHON 2026

3

DarkCall answers each problem with a different proof system. REP3 multi-party computation splits each bid into secret shares, so no operator can read one. The three operators then generate one zero-knowledge proof of the price together from those shares, with coNoir, so no one ever holds the bid book. Halo2 proves that each of the six payouts matches the proven result. And the escrow is a 2-of-3 FROST key made by a distributed key generation, so no master key exists. Everything settles in one shielded Zcash transaction.
